# 电子书资源库

入口：`/resource-library?tab=books`。

电子书直接使用本地 PT 资源缓存，标准分类为 `book`，无需创建统一图书模型或数据库迁移。

## 使用

1. 在站点设置中配置 MTeam API 地址（如 `https://api.m-team.io`）、API Key 和代理。
2. 在任务管理中使用已有的手动或定时 PT 同步任务同步电子书，过滤条件为 `mode: normal`、`categories: ["427"]`。
3. 打开电子书页，使用站点、书名/资源标题和免费条件筛选本地缓存；向下滚动每次自动追加 24 条。点击「搜索」或按回车重新查询；清空搜索框恢复列表。
4. 点击封面查看详情、豆瓣评分和图书链接；「获取书籍简介」按需调用站点详情接口。
5. 点击「下载」使用现有下载器和保存路径配置创建下载任务。

电子书页仅提供资源浏览和下载，同步配置、执行进度及历史统一在任务管理中查看。页面切换时暂停滚动监听。

## MTeam 数据映射

| 响应字段 | 用途 |
| --- | --- |
| `category: "427"` | 电子书分类 `book`；缺少站点分类映射时也能识别 |
| `name` | 原始种子标题 |
| `smallDescr` | 书名，优先作为卡片展示标题 |
| `imageList` | 图书封面，通过现有图片代理展示 |
| `douban` / `doubanRating` | 豆瓣图书 ID 和评分 |
| `status.seeders` / `status.leechers` | 做种与下载人数 |
| `size` / `createdDate` | 文件大小和发布时间 |

已有缓存再次同步会更新分类、封面和原始响应。详情请求复用站点适配器配置，保留实际 API 地址、认证和代理。此功能提供资源浏览和下载，不提供在线阅读或独立图书元数据识别。

## 验证

`tests/unit/test_books.py` 使用模拟 MTeam 响应和隔离内存数据库，验证字符串分页信息、缺失分类映射、缓存修复、搜索通配符转义、免费筛选和稳定分页。
