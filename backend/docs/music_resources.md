# 音乐资源库

入口：`/resource-library?tab=music`。

音乐页和电子书页共用资源库组件，支持站点筛选、标题/副标题关键词搜索、仅免费筛选、下拉自动加载、封面流光占位与骨架卡片、资源详情及现有下载器下载。音乐使用方形封面，豆瓣链接指向 `music.douban.com`。页面只提供本地缓存资源浏览，没有同步按钮。

在任务管理中创建或编辑 PT 同步任务：选择馒头站点，资源模式选择「仅音乐资源」，分类可留空。后台复用 `PTResourceSyncHandler`，对应 MTeam 请求：

```json
{"mode":"music","visible":1,"categories":[],"pageNumber":1,"pageSize":100}
```

任务支持手动和周期执行。根据需要设置同步类型、最大页数和请求间隔；同步完成后点击音乐页的「搜索」重新加载列表。

MTeam 分类 `406` 和 `434` 在缺少站点分类映射时也映射为 `music`。音乐模式返回的其他分类也统一归入音乐，避免遗漏该模式的资源。原始标题、中文副标题、豆瓣音乐 ID 和评分、封面、文件大小、做种人数以及促销信息使用现有 PT 资源字段，无需迁移。

验证：`tests/unit/test_music.py` 覆盖音乐类别兜底、同步参数校验、MTeam 请求结构、字符串分页信息和已有任务处理器参数传递。
